## 1. 요약
- 비디오 행동 인식 모델의 설명 가능성을 높이기 위한 프레임워크인 DANCE를 제안합니다.
- DANCE는 행동을 예측할 때 아래 3가지 분리된(Disentangled) 개념을 기반으로 설명합니다.  
	- (1) 동작 역학(Motion Dynamics - 사람 포즈 시퀀스)
	- (2) 객체(Objects) 
	- (3) 장면(Scenes)
- 라벨이 없는 Unsupervised/Label-free 방식으로 개념을 자동 추출하며, 사전 학습된 백본과 최종 분류기 사이에 개념 레이어를 두는 Concept Bottleneck 구조를 사용합니다. 실험을 통해 예측 성능을 유지하면서도 인간이 이해하기 쉬운 직관적이고 구조화된 설명을 제공함을 입증했습니다.


---
## 2. 문제 정의
- 기존 비디오 설명 가능 인공지능(Video XAI) 연구들은 아래 한계를 가지고 있었다.

### 1). 영역 강조 방식(Saliency/Attribution-based)의 얽힘(Entanglement) 문제:

- 기존 방식(3D-GradCAM, Saliency Tubes 등)은 비디오 프레임의 특정 spatio-temporal 영역만을 하이라이트합니다. 
- 이로 인해 모델이 '사람의 동작'을 보고 예측했는지, '배경'이나 '착용한 옷/객체'를 보고 예측했는지 구분이 불가능합니다.(이를 '개념이 얽혀있다(Entangled)'고 표현합니다.)
### 2). 언어 기반 설명(Language-based)의 암묵적 지식(Tacit Knowledge) 한계:

- 텍스트 설명 방식은 공간적 맥락(객체, 배경) 설명에는 유용하나, '동작의 흐름(Motion Dynamics)'을 언어로 표현하기 어렵습니다.

- 복잡한 몸짓 변화를 글로 설명하면 지나치게 길어지고 직관적인 이해가 어렵습니다.


---
## 3. 아이디어
- 인간이 행동을 인지할 때 '시간에 따른 움직임'과 '주변 공간적 맥락'을 분리하여 인식한다는 뇌과학/인지과학적 특성에 착안했습니다.  

- 개념의 분리 (Disentanglement):
	- Motion Dynamics Concept
		- 복장이나 배경에 영향을 받지 않는(Appearance-agnostic) 2D 사람 포즈 시퀀스(Pose Sequence)로 정의하여 움직임 패턴을 시각적·직관적으로 표현합니다.
		- 옷 색깔, 얼굴, 배경을 전부 지우고 사람의 뼈대 움직임만 보여준다.
		- 예: "모델이 이 '상체 회전 뼈대 움직임'을 70% 비중으로 반영했음"
	- Object & Scene Concept  
		- LLM(GPT-4o) 및 Vision-Language 모델을 활용하여 행동과 관련된 객체와 장면 텍스트 개념을 자동으로 생성 및 매핑합니다.
		- 사물(Object)와 장면(Scene)은 텍스트로 보여준다.
		- 예: "야구 방망이"라는 객체를 40% 비중으로 반영했음
		- 예: "야구장"이라는 배경을 50% 비중으로 반영했음
	
- Ante-hoc Concept Bottleneck 모델 구조
	- 모델이 최종 클래스를 예측하기 전, 반드시 분리된 3가지 개념들의 활성화(Concept Activation)를 거치도록 설계하여 설명의 신뢰성(Faithfulness)을 보장합니다.
	- "글로 설명하기 힘든 '몸짓(동작)'은 뼈대 애니메이션으로 보여주고, '배경과 사물'은 텍스트로 깔끔하게 떼어내어, 모델이 각각을 몇 %씩 참고해서 정답을 맞혔는지 한눈에 보여주는 방식.

## 4. 구현

- DANCE는 별도의 사람의 수동 라벨링 없이 자동화된 단계를 거쳐 학습됩니다.

### 1). 개념 발견 (Concept Discovery):

- Motion: 비디오에서 주요 키프레임/키클립을 추출하고, 2D Pose Estimator(ViTPose 등)로 포즈 시퀀스를 얻은 후 클러스터링(FINCH)을 수행하여 대표 포즈 시퀀스 개념들을 정의합니다.

- Object / Scene: LLM(GPT-4o)에 프롬프팅하여 각 행동 클래스별 연관 객체 및 장면 텍스트 캡션을 추출하고 정제합니다.

### 2). 의사 라벨링 (Pseudo Labeling):

- Motion: 각 비디오의 포즈 시퀀스가 해당 클러스터에 속하는지 여부로 이진(Binary) 라벨을 부여합니다.

- Object / Scene: Vision-Language 모델(InternVid 등)의 비디오 임베딩과 텍스트 임베딩 간 코사인 유사도를 이용해 유사도(Soft label)를 계산합니다.

### 3). 2단계 모델 학습 (Training):

- 1단계 (Concept Layer Training): 고정된(Frozen) 비디오 백본 특징을 받아 각 개념 레이어가 라벨을 예측하도록 학습합니다. (Motion: Binary Cross-Entropy Loss, Object/Scene: Cosine Cubed Loss 사용)

- 2단계 (Interpretable Classifier Training): 학습된 개념 레이어의 출력값(Activation Vector)만을 입력받아 최종 행동 클래스를 분류하는 선형 레이어를 학습합니다 (Sparsity L1 정규화 적용).

## 5. 성능

### 1). 정확도 (Action Recognition Accuracy):

4개 데이터셋(KTH, Penn Action, HAA-100, UCF-101) 실험 결과, 설명 가능성을 제공하지 않는 일반 백본 모델 대비 성능 저하가 미미하거나 일부 데이터셋(KTH, Penn Action)에서는 오히려 성능이 향상되었습니다.

기존의 텍스트 기반 CBM(LF-CBM)이나 전문가 정의 속성 기반 CBM보다 뛰어난 분류 정확도를 기록했습니다.

### 2). 설명력 및 해석 가능성 (Interpretability & User Study):

정량적 사용자 조사(User Study)에서 DANCE의 설명 방식이 기존 3D-Saliency(VTCD)나 텍스트 기반 설명 방식보다 훨씬 직관적이고 이해하기 쉽다는 평가(70% 이상 선호)를 받았습니다.

동작 개념(Motion Dynamics Concept)의 직관성에 대해 5점 만점 중 4.3점의 높은 평점을 기록했습니다.

### 3). 디버깅 및 모델 편집 (Model Editing & Debugging):

잘못 예측된 샘플에서 잘못 작용한 개념의 개입을 차단(Deactivation)하여 올바른 예측으로 교정할 수 있음을 확인했습니다.

도메인 시프트 환경(UCF-101-SCUBA)에서 재학습 없이 단순 가중치 수정만으로 분류 정확도를 높이는 성능 복원력을 증명했습니다.
